# Resume Generator

## 📌 Overview
Resume Generator is a web-based application that helps users create professional resumes quickly and efficiently. Users can input their details, choose a template, and generate a well-formatted resume in various formats.

## 🚀 Features
- Easy-to-use interface
- Multiple resume templates (Upcoming Feature)
- Export resumes in PDF format
- Editable sections for customization
- Save and manage multiple resumes
- Add multiple work experiences, academic qualifications, and projects
- Social media and contact information fields

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 📖 Requirements for Resume Generation
The website requires users to fill in the following details:

### **1. Personal Information**
- Full Name
- Address
- Social Media Links (Facebook, Instagram, LinkedIn)

### **2. Professional Information**
- Objective
- Work Experience (Can add multiple entries)
- Academic Qualification (Can add multiple entries)
- Projects (Can add multiple entries)

### **3. Resume Generation**
- A "Generate Resume" button to process and format the entered details into a resume.

## 📖 Installation
To set up the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/RishiSoni252004/Resume_Generator.git
   ```
2. Navigate to the project directory:
   ```bash
   cd resume-generator
   ```
3. Open `index.html` in your browser to start using the application.

## 🔧 Usage
1. Open the application in your browser.
2. Fill in the required fields with personal and professional details.
3. Select a resume template (if available in future versions).
4. Preview and download your resume.
